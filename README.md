---

## 🎯 What this repository is

This lab is my **public showcase** of skills and methods. It contains:

- 📘 **Research method notes**: step-by-step guides (survey design, PLS-SEM, reliability and validity)
- 🐍 **Reusable analysis code**: Python scripts that run on **synthetic or public data**
- 🗄️ **SQL case studies**: business questions answered with SQL
- 📊 **Dashboards**: Tableau and Excel work with business recommendations
- 🧩 **Templates**: the structure I use for every research project

> 🔒 **Note on unpublished research:** Work-in-progress and under-review manuscripts are kept in
> private repositories. They are added here **only after publication**, with full citation and DOI.
> Raw survey data is never shared publicly without participant consent and ethics approval.
