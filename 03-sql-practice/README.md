# 🗄️ SQL Practice

Business-question SQL case studies. Each case follows the same format:

1. **Business question**: what a manager wants to know
2. **Data**: a public or synthetic dataset and its schema
3. **Query**: commented SQL
4. **Insight**: what the result means
5. **Recommendation**: what the business should do
